Fixed cross-site scripting vulnerabilities in the report subsystem. Report cell data, including request-supplied extra column names, reached the browser unescaped, and request-supplied `uri_`/`url_` parameters could inject `javascript:` links. Cell data is now HTML-escaped, and report links and extra columns are taken only from report configuration. See the release notes for the behaviour change this implies. (GHSA-8gqp-wvmf-4hjj)
